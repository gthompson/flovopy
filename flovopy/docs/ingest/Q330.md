# Quanterra Q330 — baler/B14/B44 to SDS

[Index](README.md) · [Quick start](Quick-Start.md) · [CLI](Configuration-and-CLI.md) · [StationXML](StationXML.md) · [QC](Validation-and-QC.md) · [SDS merging](SDS-Merging.md)

## 1. Retain original baler media and logs

Archive the original Q330/B14/B44 download in `00_download/Q330/`. Preserve SOH, administrative and log channels as well as waveforms. **Do not assume** all `.sdr` or baler files are valid MiniSEED: test representative files with ObsPy/EPIC utilities first.

## 2A. Python/ObsPy path

```bash
python -m flovopy.ingest.cli stage-instrument q330 \
  /data/SVC1/00_download/Q330 \
  /data/SVC1/20_archive/Q330/SDS
python -m flovopy.ingest.cli stage-instrument q330 \
  /data/SVC1/00_download/Q330 \
  /data/SVC1/20_archive/Q330/SDS --execute
```

The shared adapter includes `.sdr` among its candidate extensions, but only stages files readable as MiniSEED by ObsPy. Confirm that the discovered count covers all channels, SOH and day volumes. The stage must be empty.

## 2B. EPIC `dataselect` path

For B14/B44 layouts, use the documented patterns in [EPIC](EPIC.md) and adjust them to the actual baler directory. Run `dataselect` into a separate `DAYS/` working directory; use [generic MiniSEED staging](MiniSEED.md) to create SDS. Do not merge an unreviewed Q330 download directly into master SDS.

## 3. Metadata and QC

Verify clock/GPS issues, packet gaps, overlaps, mass position and SOH; inspect any header corrections. Construct response/epoch metadata in [Nexus](StationXML.md). See [QC](Validation-and-QC.md) and [SDS merging](SDS-Merging.md).
